# ✂️ Telegram Bot: Удаление фона + Векторизация в SVG / PNG / JPEG

Бот для Telegram, который удаляет фон с изображений и конвертирует их в нужный формат (**PNG**, **SVG**, **JPEG**).

### 🚀 Главные преимущества:
* **Без платных API и без тяжелых ИИ**: Не требует покупки ключей API (Remove.bg, Clipdrop и т.д.) и не использует гигабайтные нейросети, которые не влезают в Serverless-лимиты.
* **Быстродействие**: Обработка занимает от **10 до 200 миллисекунд** (в сотни раз быстрее тяжелых нейросетей).
* **Готов к развертыванию на Vercel 24/7**: Потребляет минимум ресурсов и идеально укладывается в бесплатные лимиты Vercel Serverless Functions.
* **Векторизация в SVG**: Использует быстрый движок `vtracer` для преобразования растровых силуэтов в масштабируемый векторный код SVG.

## 🛠 Возможности

1. **Удаление фона**:
   - **Авто-режим (`auto`)**: Бот сам оценивает границы фото. Если фон однородный (студийный, белый, цветной лист) — использует FloodFill, если сложный — алгоритм GrabCut.
   - **Студийный фон (`floodfill`)**: Заливка по контуру, сохраняющая внутренние детали похожего цвета (например, белая футболка на белом фоне).
   - **Сложное фото (`grabcut`)**: Классический графовый алгоритм сегментации OpenCV.
2. **Форматы вывода**:
   - `/png` (или по умолчанию) — изображение с прозрачным альфа-каналом. Отправляется файлом-документом, чтобы Telegram не сжимал и не затирал прозрачность.
   - `/svg` — чистый масштабируемый векторный файл.
   - `/jpeg` — вырезанный объект на аккуратном белом фоне.
3. **Удобный интерфейс**:
   - Можно указать формат прямо в подписи к фото: `/svg`, `/png`, `/jpeg`.
   - Можно ответить на ранее отправленное фото командой `/svg`.
   - Под каждым результатом прикрепляются **инлайн-кнопки** для мгновенного скачивания в других форматах в один клик.

## 💻 Быстрый локальный запуск

1. Склонируйте репозиторий или перейдите в папку проекта.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте токен.
4. Откройте файл `.env` и укажите ваш токен:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ123456789
   ```
5. Запустите бота:
   ```bash
   python bot.py
   ```
   *Теперь откройте вашего бота в Telegram, отправьте ему фото и проверьте результат!*

## 🌐 Развертывание на Vercel (24/7 Бесплатно)

Vercel предоставляет бесплатный Serverless-хостинг, на котором бот будет работать круглосуточно.

### Шаг 1. Загрузка в GitHub
1. Создайте новый репозиторий на [GitHub](https://github.com/).
2. Запушьте проект:
   ```bash
   git add .
   git commit -m "Initial commit for Telegram BG Bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

### Шаг 2. Импорт в Vercel
1. Зайдите на [Vercel.com](https://vercel.com/) (войдите через аккаунт GitHub).
2. Нажмите **"Add New..."** -> **"Project"**.
3. Выберите ваш репозиторий с ботом и нажмите **"Import"**.
4. В разделе **"Environment Variables"** добавьте переменную:
   - **Имя (Key)**: `BOT_TOKEN`
   - **Значение (Value)**: `ваш_токен_от_BotFather`
5. Нажмите кнопку **"Deploy"**.

### Шаг 3. Привязка Telegram Webhook
После завершения деплоя Vercel выдаст вам публичный домен (например, `https://my-bot.vercel.app`).

Чтобы бот начал получать сообщения:
1. Просто откройте в браузере страницу:
   ```
   https://my-bot.vercel.app/?action=set_webhook
   ```
2. Вы увидите подтверждение:
   `Webhook успешно установлен на: https://my-bot.vercel.app/api (Результат: True)`.

**Готово!** Теперь ваш Telegram-бот работает на Vercel 24/7 и готов обрабатывать фотографии в любое время.
